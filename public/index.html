Host

Not hosting.
Generates and saves the terrain within the radius of the world spawn now, so that players do not wait for it later. Players can play meanwhile: it pauses whenever the server falls behind. It never starts by itself; an unfinished one waits here after a restart.

How players join

  1. Open Eaglercraft 1.8.8 (e.g. eaglercraft.com, or this host's copy at /client/).
  2. Multiplayer → Direct Connect → Join Shared World.
  3. Enter one of the join codes shown here and press Join World.

The world is registered on several relays at once and every relay hands out its own code. All codes lead into the same world. A code only works on its own relay, so use the code of a relay the player's client has (the client tries every relay in its list; others can be added under Network Settings). Players connect peer-to-peer over WebRTC; the relay's STUN/TURN servers handle NAT. Peers can see each other's IP addresses, as in the normal game.

A code changes when a relay loses the connection to the host: the relay registers the world again with a new code and never gives the old one back. The world and its players are not affected, and the code here is always the current one. eaglercraft.com lists worlds on relay.eaglercraft.net only and closes a listing a few minutes after its code stops working; Re-list there takes the new code. A relay's shared-world list in the game shows a world only to players on the host's own network, so players elsewhere need a code.

The host runs as a separate background process. Closing this page or the UI server does not disconnect anyone. Use Stop to shut it down cleanly.

Game rules are saved in the world. The other switches (PvP, flying, idle kick, command blocks) last only while the world runs, so the host sets them at every start. Unticking Game Rules leaves the world as it is and puts those switches back to the game's own values. Not offered on purpose: "spawn animals" and "spawn villagers" (in this game version switching them off deletes the animals or villagers already there, pets included) and "max players" (not enforced by this game version; use "Player limit" above). Difficulty, view distance and the LAN game mode are above.
